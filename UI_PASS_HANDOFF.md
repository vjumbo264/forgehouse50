## 2. Screens Touched & Visual Weaknesses Noticed

### Screen 1: The Reader Experience (`ReadScreen.kt` and web reader)
- **Header**:
  - The top bar is functional and no longer truncates mid-word, but typography could be elevated with a more distinguished display style.
  - The 'Aa' text size button and translation picker chip need refined icon alignments and subtle tonal container backgrounds matching M3 Expressive surfaces.
  - The chapter progress line and the 'Chapter X of Y' sub-row could benefit from smoother spacing so it feels like an organic part of the header rather than a secondary bar.
- **Reading Counters**:
  - The 'verses left · chapters left' chip updates smoothly, but its pill shape and typography should be balanced against the text content so it remains unobtrusive.
- **Unified Bottom Dock**:
  - The dock successfully eliminates overlapping panels and provides a 98% opaque background, but the shadow/elevation gradient and divider border need a softer, more premium transition into the reading canvas.
  - The timer display and 'Mark day complete' button in reading state should harmonize perfectly with the 'v. X' selection toolbar state during spring height animations.

### Screen 2: Today / Home Dashboard (`HomeScreen.kt` and web home)
- **Dynamic Intrinsic Cards**:
  - Cards now expand dynamically in priority order without fixed-height squeezing, but the vertical padding between cards (currently 12dp/16dp) should be tuned to standard SpacingTokens for an airy, uncluttered feel.
  - Skeletons for Today's reading card should have subtle, shimmering tonal gradients rather than flat placeholders.
- **Update Ready Card**:
  - Prominent card with wavy progress indicator is functional, but button typography and install badge need tighter visual grounding.
- **Community & Announcement Cards**:
  - The quote snippet and leader reply in the home preview card should use consistent blockquote borders and distinct tonal backgrounds (surfaceContainerLow vs surfaceContainer).

### Screen 3: Bible Translations Screen (`TranslationsScreen.kt` and web manager)
- Unified single destination exists across Profile and Reader.
- The live download progress row (wavy indicator + percentage + bytes) works, but the spacing around version rows, language tags, and the 'Built in' / 'Active' badges can be made sharper and more uniform.
- Empty search state needs calm, friendly illustration or M3 iconography.

### Screen 4: Notes, Feedback, & Modals (`NotesScreens.kt`, `SendFeedbackState`)
- **Note Composer**:
  - The book/chapter/verse pickers are functional, but their touch targets and dropdown styling should align with M3 ExposedDropdownMenu standards.
  - The Expressive send animation (spinner -> checkmark 'Sent') is effective; verify spring easing and checkmark icon size.
- **My Notes List**:
  - Status badges ('Sent', 'Answered', 'Private') should use consistent M3 tonal badge tokens.
  - Timestamps (WAT) should use clean, subtle labelMedium typography in onSurfaceVariant.

### Screen 5: Scripture Quote Cards (`QuoteImageGenerator.kt` & Admin Share)
- 1080x1350 px cards with 3 palettes render accurately.
- In the UI, the preview dialog and 'Share as image' button in Leaders' Inbox need refined action button placement and loading states during bitmap generation.

### Screen 6: Profile & 'What's New' Changelog (`ProfileScreen.kt`, `ChangelogScreen.kt`)
- 'Since you last updated' summary card at the top of ChangelogScreen is clean, but could have a distinctive brand accent border or gentle tonal surface.
- Collapsible older release cards should have smooth chevron rotation transitions and consistent inner padding.

### Screen 7: Leaders' Inbox & Community History
- Community history list cards should adopt the refined quote typography.
- Filter chips and search bar in LeadersInboxTab should maintain 48dp touch targets and clear active states.
